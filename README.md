# Endeudados

**Endeudados** es una aplicación web orientada a jóvenes profesionales en Colombia que buscan organizar y comprender mejor sus finanzas personales.

El proyecto permite gestionar información financiera como ingresos, gastos y deudas, con el propósito de identificar hábitos de consumo, detectar posibles gastos innecesarios y facilitar la toma de decisiones frente al sobreendeudamiento. También contempla herramientas de análisis y priorización de obligaciones mediante el método de avalancha.

La aplicación utiliza una arquitectura modular por pantallas, en la que cada funcionalidad cuenta con sus propios archivos HTML, CSS y JavaScript. Esto facilita el mantenimiento del código, el trabajo colaborativo y la incorporación de nuevas funcionalidades.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript vanilla
- Supabase para autenticación y base de datos
- Git y GitHub para el control de versiones
- Vercel para el despliegue de la aplicación

## Objetivo

Brindar una herramienta sencilla y accesible que ayude a los usuarios a visualizar su situación financiera, reconocer patrones de gasto y tomar decisiones más organizadas para mejorar su salud financiera.

> Endeudados se encuentra en desarrollo y sus funcionalidades se irán ampliando progresivamente.
